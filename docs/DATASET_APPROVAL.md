# Dataset approval checklist

Before importing:
1. Obtain the exact dataset name and source URL from your faculty.
2. Confirm academic-use permission and license.
3. Confirm whether records are genuine cloud audit logs and which provider they represent.
4. Confirm whether fields contain personal or sensitive information.
5. Keep the original dataset unchanged and work on an approved copy.
6. Document the field mapping used for import.
7. Do not fabricate missing records or claim simulated records are real evidence.

The application import currently accepts JSON arrays of normalized event objects.
